# burakcokyildirim/tap

Homebrew casks for [Clawde](https://github.com/burakCokyildirim/clawde), a desktop pet that acts out
your Claude Code sessions.

```bash
brew install --cask burakcokyildirim/tap/clawde
```

Clawde keeps itself up to date once it's installed. The cask here is bumped by Clawde's release
workflow each time a version ships.
